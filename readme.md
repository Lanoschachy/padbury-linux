# Padbury Linux

Minimalist Padbury-style screensaver for Linux Mint and Ubuntu.

## Features

- Fullscreen clock
- Auto launch after idle
- Exit on keyboard or mouse movement
- Automatic installer

## Installation

chmod +x installer.sh
./installer.sh
